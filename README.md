В работе сравниваю пять моделей рекомендаций новых товаров: **ItemKNN, iALS, EASE, FM с метаданными и iALS с собственным сигналом**.
Реализации находятся в `models/`. Основной отчёт с выполненными ячейками, формулами, графиками и подбором параметров —
[experiments.ipynb](experiments.ipynb).

## Данные и оценка

После очистки осталось **391 150 покупок, 4 334 пользователя и 3 659 товаров** (266 221 уникальная пара).
Исходный набор содержит 541 909 строк. Удалены пропуски идентификаторов, отмены, неположительные цены и количества,
служебные коды и точные дубликаты. Используется весь очищенный набор.

Рекомендую 10 ещё не купленных товаров. Релевантность — покупка нового товара в следующем временном окне.
Train: до 01.09.2011; validation: 01.09–14.10.2011; test: с 15.10.2011 до конца набора.
После подбора переобучаю модели на train + validation. Пользователи, каталог кандидатов и исключение известных товаров одинаковы для всех моделей.
Новые пользователи и товары исключаются; подробные правила и число исключений приведены в ноутбуке.

FM использует ID, страну покупателя, слова из названия и ценовой дециль товара, полученные только из прошлых покупок.
Собственный сигнал iALS: `p_RF = (1 - exp(-n_invoices/2)) * 2**(-age_days/half_life)`.
Он меняет целевое предпочтение; confidence остаётся как у базового iALS.

## Результаты

Test: 1 587 пользователей, каталог из 3 556 товаров до исключения истории каждого пользователя.
Основная метрика — NDCG@10; вторая — Recall@10. Обе усредняются по пользователям.

| Модель | NDCG@10 | Recall@10 | Precision@10 | Coverage@10 |
|---|---:|---:|---:|---:|
| EASE | 0.1026 | 0.0583 | 0.0877 | 0.2396 |
| ItemKNN | 0.0966 | 0.0550 | 0.0812 | 0.2629 |
| iALS | 0.0939 | 0.0538 | 0.0794 | 0.2821 |
| iALS с собственным сигналом | 0.0849 | 0.0494 | 0.0715 | 0.2182 |
| FM с метаданными | 0.0752 | 0.0418 | 0.0672 | 0.1957 |

Лучший результат у EASE с `reg=1000`. Собственный сигнал снизил NDCG iALS на 0.0090.
Добавление метаданных FM не дало уверенного улучшения относительно FM только с ID.
Полные таблицы, выбранные параметры и [выводы](results/conclusions.md) находятся в `results/`.
Оценка ограничена одним магазином и периодом, известными активными пользователями и небольшой сеткой параметров.

## Запуск

Нужен Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_notebook.py
```

На Windows окружение активируется командой `.venv\Scripts\activate`.
При первом запуске данные автоматически скачиваются с UCI в `data/` (архив 22.6 MB).
Скрипт выполняет весь ноутбук и сохраняет результаты. Также можно открыть ноутбук в Jupyter/VS Code,
выбрать Python из `.venv` и выполнить Run All. Желательно иметь 2–4 GB свободной памяти.

Для повторения зафиксированы seed=42, версии библиотек, один вычислительный поток, даты и параметры.
Архив проверяется по SHA256; данные, окружение, кеши и веса исключены через `.gitignore`.

Вспомогательные файлы: `data_utils.py` — загрузка, подготовка и признаки; `evaluation.py` — метрики;
`figures/` — графики; `tests/` — проверки формул и оценки. Проверки запускаются так:

```bash
python -m unittest discover -s tests -v
```
